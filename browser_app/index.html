Data and methodology

How the prototype works

SOH is measured discharge capacity divided by initial capacity × 100.

RUL is cycles until the first observed SOH ≤ 80%. If retirement is never observed, RUL remains unknown.

Sensor degradation changes the input features. The target labels remain fixed. Imputation and scaling use training batteries only.

Live inference uses the exact exported Ridge, Random Forest, Gradient Boosting and cycle-only model parameters. Browser random-noise samples are reproducible within this interface; they use a different random-number generator from NumPy.

Precomputed robustness results were calculated in Python. For NASA MAT/CSV import, retraining on your own data and new full experiments, run the included Streamlit application.

Cell-level laboratory experiments do not establish pack-level safety or real-vehicle accuracy.
